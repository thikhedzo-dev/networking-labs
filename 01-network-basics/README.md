# Lab 01 — Network Basics

## Objective

Build a basic understanding of computer networking and establish connectivity between devices using Cisco Packet Tracer.

## Topics

- Computer networks
- LAN and WAN
- Network devices
- OSI model
- TCP/IP model
- MAC addresses
- IPv4 addresses
- Subnet masks
- Default gateway
- Ethernet
- ARP
- TCP and UDP
- DNS
- DHCP
- Basic network troubleshooting

## Tools

- Cisco Packet Tracer
  

## Practical Lab

A simple LAN will be created using:

- 2 PCs
- 1 Cisco switch

The PCs will be assigned IPv4 addresses and connectivity will be tested using `ping`.
